## Предметная область

ROT13 — симметричное преобразование строки: каждая **латинская** буква сдвигается на 13 позиций в алфавите. Повторное применение возвращает исходный текст (**самодвойственность**). Неалфавитные символы (цифры, пробелы, кириллица, знаки) не изменяются. Метод не является криптографической защитой; используется для обфускации и учебных целей.

Подробный анализ: [`PR7.2_efanova_lopatina/Documents/01_Analiz_trebovaniy.md`](PR7.2_efanova_lopatina/Documents/01_Analiz_trebovaniy.md).
